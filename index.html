Comment ça marche ?
  1. Regarde la vidéo qui t'intéresse sur TikTok.
  2. Dans ses commentaires, repère le commentaire épinglé : il contient le code du guide.
  3. Entre ce code ici : le guide s'ouvre. Chaque vidéo a son propre guide et son propre code.
Ça ne marche pas ?
  • Vérifie le code : 8 caractères, sans le chiffre zéro ni la lettre O (ni I, ni L, ni 1).
  • Ouvre cette page dans Safari ou Chrome plutôt que dans l'appli TikTok.
  • Si le téléchargement ne démarre pas, utilise « Ouvrir dans le navigateur ».
  • Le code de la vidéo d'hier n'ouvre pas le guide d'aujourd'hui : chaque guide a le sien.

Gratuit. Cette page ne collecte aucune donnée : ton code est vérifié sur ton appareil, rien n'est envoyé.
